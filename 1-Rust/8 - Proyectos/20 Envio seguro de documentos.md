# SecureExchange

Se trata de hacer un sistema web que envie ficheros de manera segura

El sistema:

- El sistema registrara a un usuario con su email
- El usuario asociara a su email, claves publicas
- El usuario puede buscar a un usuario por su email
- Obtenida su clave publica puede crear dh para encriptar
- El usuario encripta el documento y lo envia al servicio.
- El destino puede recibir el fichero y desencriptarlo.
