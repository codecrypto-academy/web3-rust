# Bdd distribuida

Se trata de practicar con una base de datos distribuida

Las funciones a implementar son:

- Instalar etcd en local en tres procesos.
- Hacer una web que permita crear wallet que guardaremos en localStorage
- Hacer traspasos entre cuentas grabando tx firmadas.
  Clave TXTO-ORIGEN-DESTINO
  Clave TXFROM-DESTINO-ORIGEN
  Clave BAL-CUENTA
  Clave FECHA
  Clave DEPOSIT-CUENTA
  Clave RETIRNO-CUENTA
- Hacer deposit basandose en la pasarela de redsys.
