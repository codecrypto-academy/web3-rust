## INSTALAR Visual Studio Code:
### Introducción

Una vez que descarguemos Rust, lo siguiente que necesitamos hacer es elegir un IDE (entorno de desarrollo integrado). Hay muchas opciones con sus pros y sus contras, yo recomiendo usar Visual Studio Code debido a que es gratuito y es utilizado por la mayoría de los programadores. Además sirve para varios lenguajes de programación.

Si estás acostumbrado a utilizar otro IDE, no hace falta que aprendas a utilizar uno nuevo, casi todos los entornos de desarrollo tienen extensiones que trabajan con Rust y nos ayudan a compilar en tiempo real para poder corregir errores a medida que vamos programando.

Para instalar VS Code, vamos a la pagina oficial para [descargarlo](https://code.visualstudio.com/) y el navegador debería reconocer el sistema operativo que estamos usando. Presionamos el botón de descarga con el nombre de nuestro sistema operativo y la arquitectura correcta.

Una vez descargado, damos doble click en el instalador y seguimos las instrucciones del asistente. 

Recomiendo instalar algunas extensiones dentro de VS Code para mejorar la experiencia de programación. Entre ellos están:

- `rust-analyzer`: compilador en tiempo real, ayuda a completar el código, sugiere importar módulos, infiere tipos, entre otras cosas.
- `crates`: ayuda a gestionar dependencias.
- `Even Better TOML`: ayuda a visualizar archivos con extensión `.TOML`.
